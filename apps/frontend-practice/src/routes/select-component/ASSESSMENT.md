# Select Component

Build an accessible custom `Select` component in React + TypeScript.

Requirements:

- Closed state shows placeholder or selected value.
- Clicking opens a listbox of options.
- Selecting an option updates the form value and closes the list.
- Keyboard support: ArrowUp, ArrowDown, Enter, Escape.
- Blur / outside click behavior should be handled cleanly.
- Support disabled options.
- Integrate it into a small form with validation.
